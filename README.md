# 🏬 تطبيق إدارة الأصناف التجارية ومخزون المحلات (Shop Prices)

تطبيق محلي احترافي (**Offline-first**) لإدارة المنتجات، الأسعار، المخزون، وأسعار الصرف اليومية للمحلات التجارية والمستودعات الصغيرة والمتوسطة، مبني بتقنية **Flutter** و معمارية **Clean Architecture**.

---

## 🌟 الميزات الرئيسية (Key Features)

### 📦 1. إدارة المنتجات والمخزون (Product & Stock Management)
- **إضافة وتعديل الأصناف:** تسجيل اسم المنتج، سعر الشراء والبيع، عدد الحبات في الباكت، حد الأمان، والعملة.
- **تتبع المخزون بالباكت والحبة:** سحب وإضافة مخزون فوري مع زر زيادة خفيف وضغطة زر واحدة.
- **تنبيهات نقص المخزون:** تنبيه الألوان والأعداد للأصناف التي اقتربت من النفاد.
- **صلاحية المنتجات:** تتبع تاريخ الانتهاء وإشعارات تلقائية للأصناف المنتهية أو القريبة (خلال 30 يوماً).
- **صور وتفاصيل غنية:** التقاط صور المنتجات من الكاميرا أو المعرض مع ضغطها تلقائياً للحفاظ على أداء وسرعة التطبيق.

### 💱 2. إدارة أسعار الصرف والعملات (Multi-Currency & Exchange Rates)
- **دعم 3 عملات رئيسية:** الريال المحلي (ر.ي)، الريال السعودي (ر.س)، والدولار الأمجد ($).
- **جدول صرف يومي:** تحديد سعر الصرف اليومي للعملات الأجنبية مقابل العملة المحلية.
- **تحويل وتقييم فوري:** عرض وحساب تكلفة البيع والشراء والأرباح بالعملة المحلية تلقائياً بناءً على سعر الصرف الحالي.

### 🛒 3. وضع كشك البيع المفرد (POS Mode)
- شاشة بيع سريعة ومبسطة تتيح البحث باسم المنتج أو مسح الباركود.
- إضافة الحبات للسلة، حساب الإجمالي بالعملة المحلية، وخصم المخزون التلقائي فور إتمام البيع.

### 📊 4. لوحة التحكم والتقارير المالية (Dashboard & Analytics)
- **رسوم بيانية تفاعلية (`fl_chart`):**
  - رسم دائري (`PieChart`) لتوزيع المنتجات حسب الأقسام.
  - رسم بالأعمدة (`BarChart`) لأعلى 5 أقسام ربحاً بالعملة المحلية.
- **مؤشرات مالية:** إجمالي رأس المال المالي المخزّن، الأرباح المتوقعة، الأقسام الأكثر ربحاً.
- **تصدير تقارير:** تصدير كافة بيانات المنتجات والأرباح إلى ملفات **CSV** ومشاركتها عبر التطبيقات.

### 🔍 5. البحث والفرز والباركود (Search, Sort & Barcode)
- **مسح الباركود بالكاميرا:** إمكانية إضافة أو البحث عن المنتجات فورياً باستخدام الباركود.
- **فرز متعدد (9 خيارات):** (الأحدث، الأقدم، الأعلى/الأقل سعراً، الأكثر ربحاً، الأقل مخزوناً، الأقرب انتهاءً، أبجدياً).
- **تصفية بالتاريخ:** فلترة الأصناف المضافة في نطاق تاريخي محدد.

### 🌐 6. اللغات والتوجيه والواجهة (Localization & UI/UX)
- **تعدد اللغات (Arabic / English):** تبديل فوري بين العربية والإنجليزية من القائمة الجانبية (Drawer).
- **توجيه تلقائي (RTL / LTR):** محاذاة الواجهة والتبويبات العلوية تلقائياً حسب اللغة الحالية.
- **الوضع الداكن (Dark Mode):** ثيمات فاتحة وداكنة ومريحة للعين مع حفظ تفضيل المستخدم.
- **أنيميشن خفيف وحركي:** انتقالات سلسة بين الشاشات وظهور متدرج للبطاقات دون التأثير على خفة التطبيق.

### 💾 7. النسخ الاحتياطي (Backup & Restore)
- إنشاء واسترجاع نسخ احتياطية كاملة لجميع البيانات بصيغة **JSON** محلياً على الجهاز.

## 🛠️ التقنيات والمكتبات المستعملة (Tech Stack)

- **الداخلية:** [Flutter SDK ^3.6.0](https://flutter.dev) (Dart)
- **إدارة الحالة (State Management):** `Provider ^6.1.5`
- **قاعدة البيانات المحلية:** `sqflite ^2.4.1` (SQLite v4 Database Migration)
- **التخزين المحلي للتفضيلات:** `shared_preferences`
- **مسح الباركود:** `mobile_scanner`
- **الرسوم البيانية:** `fl_chart`
- **اختيار الصور:** `image_picker`
- **التنبيهات المحلية:** `flutter_local_notifications` & `timezone`
- **النسخ والتصدير:** `csv`, `file_picker`, `share_plus`, `path_provider`

## 🚀 كيفية التشغيل والتطوير (Getting Started)

1. **استنساخ المشروع أو توجيه الأمر للمجلد:**
   ```bash
   cd shop_prices
   ```

2. **تحميل المكتبات:**
   ```bash
   flutter pub get
   ```

3. **تشغيل التطبيق على الهاتف أو المحاكي:**
   ```bash
   flutter run
   ```

4. **بناء النسخة النهائية (APK):**
   ```bash
   flutter build apk --release
   ```
